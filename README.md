# agent-knowledge
simulating spatial agent knowledge

## robot-sim

`robot-sim/index.html` — a single-page three.js simulation of a robot that starts with no
knowledge of a maze-like building, maps walls with a 4 m × 65° vision cone, and replans
(A* over its own occupancy map) until it reaches a goal on the far side. Open the file in a
browser (it loads three.js from jsDelivr).
